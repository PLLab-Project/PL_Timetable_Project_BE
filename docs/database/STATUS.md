# 구현 상태

이 문서는 현재 main을 기준으로 실제 동작하는 범위와 남은 범위를 구분합니다.

## DB와 기준 데이터

- PostgreSQL 18.4 Docker Compose 실행 환경
- JDK 빌드·JRE 실행 멀티스테이지 Spring Boot API 이미지
- DB·마이그레이션·적재·API를 한 명령으로 시작하는 Compose 구성
- Flyway 12개 마이그레이션과 Testcontainers 빈 DB 검증
- 2026-1 강의 카탈로그와 공식 PDF 기준 2026-2 강의 카탈로그
- 공식 2026-2 원본 표 1,568행과 고유 분반 1,558개 감사 추적
- 마이크로전공 부록 194행의 개설·미개설·본문 불일치 상태 보존
- 2020~2026 과거 강의 개설 이력
- 2016~2026 교육과정 필수과목
- 2020~2026 학과·학번별 졸업 학점·교양요건
- 2026 학과별 졸업인증과 보존된 구 졸업요건
- 정규 학과·전공 코드, 연도별 별칭, 학사 데이터 FK 연결
- 학생 프로필의 학과도 `academic_units.code` FK로 정규화
- 공개 저장소에서 제외된 SQL 페이로드의 체크섬·멱등 적재 스크립트

## 구현 및 통합 테스트 완료

### 인증·보안

- 이메일 OTP 요청·검증과 Google OIDC 계정 연결 백엔드
- 로그인 세션 조회·유지와 로그아웃
- 회원 탈퇴 시 사용자 소유 데이터 전체 삭제와 세션 무효화
- Spring Security 세션 인증
- OTP 만료·재전송 대기·시도 횟수 제한·BCrypt 저장
- CSRF, CORS, 보안 쿠키 설정
- 다른 Origin의 SPA가 사용할 수 있는 CSRF 토큰 초기화 API

Google 로그인은 운영 표준 웹 OAuth 클라이언트와 Secret Manager를 연결해
`prod,gcp,google` 프로필로 활성화했다. Google 승인 화면과 등록된 HTTPS 백엔드
콜백 일치까지 운영에서 검증했다.

### 학사·강의·리뷰

- 학과·학기·데이터 버전 조회
- 강의·분반 조회, 과목·교수 검색, 단과대·학과·분류·학년 다중 필터
- 공식 분반 대상 학년·정원·비고·원본 강의실·복수 강의실·분류 문맥 조회
- 이름·리뷰 수·베이지안 평점·인기순 정렬
- 공개 리뷰 목록과 과목·교수별 조회
- 인증 사용자의 리뷰 작성·내 리뷰 조회·수정·삭제
- 작성자 소유권, 중복 리뷰, 별점·교수 검증

2026-2 공식 원본의 수강 대상 학년과 학과별 전필·전선 분류를 검색에 사용한다.
2026-1 원본에는 해당 분류 문맥이 없어 임의 생성하지 않는다.

### 이수과목·졸업요건

- 이수과목 직접 등록·조회·수정·삭제
- 상태·학기 필터와 학점 요약
- 내 시간표의 과목을 수강 중 이수과목으로 가져오기
- 수강 중 과목의 이수 완료 전환
- 입학연도·학과·학생 구분·전공 방식별 졸업요건 조회
- 이수학점·교양 영역·필수과목 판정
- 부족 학점·과목 안내와 현재 학기 후보 추천
- 공식 근거·정규화 경고·자동 판정 불가 항목 반환
- P/N 성적 방식과 인정 학점 분리
- Gemini 3.5 Flash-Lite 비전 성적표·시간표 OCR과 실제 분반 매칭(원본 미저장)
- 사용자 입학연도·학생구분·전공방식·학번·튜토리얼 상태 수정

### 시간표·자동 편성

- 사용자 소유 시간표 CRUD와 분반 추가·삭제
- 복수 시간표 즐겨찾기
- 분반 시간 충돌 검사
- OR-Tools CP-SAT 기반 자동 편성 작업 생성·조회·취소
- 복수 가능 시간·요일별 공강 고정, 서버 후보 직접 조회, 결과 시간표 저장
- 사용자 소유권과 학사 DB 기준 분반 검증

### API 문서

- 도메인별 Markdown API 명세와 프론트 연동 안내
- OpenAPI JSON·YAML 자동 생성
- 루트 주소에서 열리는 Scalar API 문서
- 세션 쿠키와 CSRF 요구사항의 OpenAPI 표시
- 전 API 성공·오류 `ApiResponse<T>` envelope와 공통 OpenAPI 오류 스키마
- API별 상세 설명·파라미터·요청 예제와 업무 오류 응답
- health 응답의 배포 버전·Git 커밋 식별

## 아직 구현되지 않음

- 시간표 복사·이전 학기·공유 링크
- 다른 분반 교체와 대체 분반 추천

상담 횟수, 개인별 학점 인정, 자격 증빙 유효성, 예외 승인, 학교 포털의 최종
졸업사정은 현재 데이터만으로 자동 확인할 수 없습니다.

## 공개 저장소에 포함하지 않는 항목

- 실제 사용자 계정·개인정보·세션
- OTP 원문과 운영 비밀값
- 교수명과 원천 payload를 포함할 수 있는 기준 데이터 SQL 페이로드
- 운영 DB 백업
